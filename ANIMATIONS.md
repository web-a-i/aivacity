# Айвазовский city — motion update

В этой версии добавлен motion-layer по мотивам `mfias/nova-residence.html`:

- GSAP + ScrollTrigger для entrance/reveal и scroll-linked эффектов
- Lenis для плавного desktop-скролла
- kinetic-анимация заголовков по буквам
- parallax для hero и генплана
- мягкое плавание floating-блока и hotspot-точек
- stagger-анимация карточек при появлении
- 3D tilt-эффект для карточек при наведении
- кастомный cursor на устройствах с точным указателем
- hover-scale для изображений
- `prefers-reduced-motion` для доступности

Контент и визуальные assets Айвазовского city не заменялись.
